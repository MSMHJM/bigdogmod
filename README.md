# Big Dog Mod（大狗模组）

一个 Minecraft Fabric 模组：用「大骨棒」喂成年狗使其巨大化，每个阶段的狗都可以骑乘，还能释放「嚼嚼嚼」和「坚守者音波」两种技能，并通过「生物扳手」打开改造界面安装各种升级。

## 版本目录

本仓库包含 3 个版本的源码，互相独立，请在对应目录中构建：

| 目录 | Minecraft 版本 | 说明 |
|------|----------------|------|
| `26.3-pre-2/` | 26.3-pre-2 | 主版本（预览版） |
| `26.1.2/` | 26.1.2 | 稳定版本移植 |
| `26.2/` | 26.2 | 稳定版本移植 |

## 核心玩法

- **大骨棒**：喂给成年狗，体型 +1 级（最高 3 级，每次增加 0.8）；喂毒马铃薯可降级。大狗血量按等级：1 级 30、2 级 50、3 级 70（玩家视角 1.5 / 2.5 / 3.5 排）。
- **骑乘**：每个阶段的狗都可以骑；固定视角（开车模式）下 A/D 只控制转向不前进，后退不转身、速度为前进的一半。
- **嚼嚼嚼**：对前方 5 格内的生物造成伤害，伤害按对方体型判定——体型小于大狗的生物直接吞掉，大于的按 25 点伤害攻击；对低血量生物（1/2/3 级阈值 5/10/15 血）直接吞噬并恢复自身血量。死亡提示：`...被...的大狗嚼嚼嚼了`。
- **坚守者音波**：长按蓄力（最多 5 秒），松开后按蓄力进度发射音波，蓄力时音效逐渐加快变音；20 点魔法伤害，射程随蓄力时长增加；发射后有 1 秒冷却才能再次蓄力。死亡提示：`...被...的大狗叫了`。
- **疾速冲刺**：骑乘时按 C 触发，20 秒内速度 ×3，冷却 60 秒。

技能按键（嚼嚼嚼 / 音波蓄力 / 固定视角 / 疾速冲刺）均按 Fabric 标准注册，可在 选项 → 控制 → 按键 中自定义。

## 升级系统

使用「生物扳手」对大狗右键打开改造界面，将升级物品放入升级槽（每格只能放 1 个升级物品，且只能放升级物品）。所有升级物品按住 Shift 会显示黄色用法说明。

| 升级 | 效果 |
|------|------|
| 运载升级 | 获得运载空间（容量随体型），骑乘时按 E 打开；安装后移动减速 |
| 疾速升级 | 骑乘按 C 疾速冲刺：20 秒 ×3 速度，冷却 60 秒 |
| 喷气升级 | 跳跃未落地时再按空格，向狗朝向斜上方喷气推进并免除摔落伤害，冷却 20 秒 |
| 冷却升级 | 所有升级冷却 ×85%，可叠加（2 个 80%、3 个 75%） |
| 攻击升级 | 提升伤害（满级大狗由 15 次普攻击杀坚守者提升到 10 次） |
| 极限过载 | 前置疾速升级；疾速冷却期间按 C 触发极限加速：5 秒 ×10 速度；用后变「损坏升级」、大狗掉 10 血、疾速冷却 +10 秒（可多装多个） |
| 自动恢复 | 前置运载升级；每 5 秒自动消耗运载内可喂的肉给狗回 4 血（放多个不缩短间隔） |

## 指令

游戏内使用 `/bigdog` 系列指令修改速度和转弯等级（默认均为 20）：速度 1~50，转弯 1~50，按比例生效；可指定玩家（该玩家所有狗生效），设置保存在存档文件夹，并提供恢复默认的选项。

## 构建

每个版本目录都是独立的 Fabric Loom 项目：

```bash
cd 26.2
./gradlew build
```

构建产物在 `build/libs/` 下。注意：`libs/` 目录需要放入对应版本的 Fabric API jar（构建依赖本地 jar，未随源码提交）。

## 依赖

- Fabric Loader >= 0.19.3
- Fabric API（版本与各目录对应）
- Java >= 25（26.x 系列）
